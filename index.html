Smart Transportation for SPAMAST

E-Sikad is an online transportation booking system designed for students, faculty, staff, and community members of SPAMAST. It provides safer, faster, and more convenient Sikad transportation.

HTML Link Book a Ride

Project Overview

The E-Sikad Online Booking System solves transportation challenges within the SPAMAST community by providing real-time ride booking, driver tracking, fare estimation, and centralized transportation management.

System Users

Passenger

Book rides quickly, view fare estimates, track drivers in real-time, receive notifications, and rate completed trips.

Driver

Receive booking requests, accept rides instantly, navigate passengers, and track daily earnings.

Administrator

Monitor trips, manage accounts, generate reports, and oversee transportation operations.

User Flow

Passenger Flow

Login → Book Ride → Select Destination → Fare Estimate → Driver Matching → Track Ride → Complete Trip → Rate Driver

Driver Flow

Login → Receive Booking → Accept Ride → Navigate → Start Trip → Complete Trip → View Earnings

Admin Flow

Login → Dashboard → Monitor Trips → Manage Users → Analytics → System Management
